# Cybersecurity Checklist

## 1. Password Security
- Use strong and unique passwords.
- Avoid sharing passwords.
- Use multi-factor authentication.

## 2. Device Security
- Keep software and operating systems updated.
- Use trusted antivirus software.
- Lock devices when not in use.

## 3. Internet Safety
- Avoid clicking suspicious links.
- Check website addresses before entering personal information.
- Avoid downloading files from untrusted sources.

## 4. Data Protection
- Back up important files regularly.
- Avoid sharing confidential information publicly.
- Use encryption to protect sensitive data.

## 5. Email Security
- Check the sender before opening attachments.
- Be alert to unexpected emails.
- Report suspicious messages.

## 6. Physical Security
- Keep devices in secure locations.
- Do not leave computers unattended in public places.
- Protect devices from unauthorised physical access.
